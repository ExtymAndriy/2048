🎮 2048 Game (JavaScript Implementation)

📖 Project Description
This is a browser-based implementation of the classic 2048 game, built using modern JavaScript (ES6+). The player moves tiles on a 4×4 grid, combining matching numbers to reach the 2048 tile — or even go beyond 😏
This project showcases skills in DOM manipulation, game state management, and building interactive user interfaces.


🔍 Live Demo
👉 https://extymandriy.github.io/2048/


🎯 Key Features
🎮 Classic 2048 gameplay
⌨️ Keyboard controls (arrow keys: ⬅️➡️⬆️⬇️)
🔢 Automatic tile merging
💾 High score saving
🔄 Restart functionality anytime
⚡ Smooth tile animations


🧠 How to Play
  Use the arrow keys to move tiles.
  When two tiles with the same number collide, they merge into one.
  After each move, a new tile appears on the board.
  The goal is to reach the 2048 tile.
  The game ends when no more moves are possible.

🚀 Getting Started

    1. Clone the repository
        git clone https://github.com/ExtymAndriy/2048.git
        cd 2048

    2. Install dependencies
        npm install

    3. Run the project
        npm start
